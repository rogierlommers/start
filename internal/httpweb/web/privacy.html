Privacy notice

Effective 10 October 2026

About this application

START is a private, single-user home dashboard. Its optional banking feature lets the operator connect their own ING Netherlands account through Enable Banking and display a read-only account balance.

Data the banking feature processes

  • An Enable Banking session identifier and account identifier for each connected account.
  • Each account's label, currency, and consent expiry.
  • Each current balance and the time it was retrieved.
  • Recent booked transaction amounts, dates, counterparties, and payment descriptions when supplied by ING.

START does not receive or store ING login credentials. Balances and transactions are not written to the application database. Successful responses may remain in server memory for up to five minutes to reduce requests and provide clearly marked saved values during a short provider outage. Transaction retrieval is limited to booked entries from the last 90 days.

Purpose and permission

The data is used only to show the operator their requested account balances and recent transactions. The operator explicitly authorizes access in ING's own authentication flow. Consent can be withdrawn through ING or Enable Banking.

Storage and retention

The connection references remain in the private application database until they are replaced or removed by the operator. Temporary authorization state expires after 15 minutes and can be used only once. Provider consent expires after the period approved during connection.

Third parties

Enable Banking provides the regulated account-information connection, and ING provides the underlying account data. Their own privacy notices and terms also apply. START does not sell account data or share it for advertising.

Security

The dashboard and banking endpoints require authentication. The application uses an HTTPS callback, secure session cookies, short-lived signed provider tokens, and a private signing key stored outside the web application and source repository.
